A program that draws one newspaper front-page image summing up the world news of Wednesday 18 November 2026 — 45 stories, 13 of them flat-illustrated, a by-the-numbers strip, a dotted world map with numbered pins, and briefs for the rest. Pure Python standard library; it renders with Pillow and DejaVu when available and otherwise copies the bundled pre-rendered image.

## Run it

```sh
python3 main.py output.png
```
